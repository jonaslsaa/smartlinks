Live demos

Three Smartlinks. Each is a small program living entirely in its URL — and each mints new links while you watch.

There is no backend behind these pages and nothing is deployed: no accounts, no database, just some compute. Every demo is a signed link built from the script published next to it in the repository, and on any Smartlink you can swap /r/ for /d/ in the address bar to audit exactly what it runs without executing it.

Demo 1 · Redirect

Mint a redirect link

Enter any URL and get back a freshly compiled Smartlink that redirects to it — behind a confirmation page, for a lifetime you choose between 15 minutes and 24 hours, then it expires. Handing someone an action without handing them anything else.

Open the demo → Audit the link Script source

Demo 2 · Badge

Mint a live SVG badge

Pick a label, a value, and a color and get back a Smartlink that serves that badge as an SVG image, embeddable in any HTML page. It never expires, because there is nothing anywhere to expire — the URL is the entire program.

Open the demo → Audit the link Script source

Demo 3 · Sealed riddle

Mint a riddle with a sealed answer

Write a question and a secret answer. The answer is encrypted into the new link, bound to that exact program: whoever holds it can guess against it and even read the link's full source, but the answer stays ciphertext. Sealed secrets, minted in one click.
